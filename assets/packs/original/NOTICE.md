# Original eSheep art

`animations.xml` is the `esheep64` pack from https://github.com/Adrianotiger/desktopPet
(`Pets/esheep64`): the animation data and the code of that project are MIT licensed; the sheet is an
image rip by LiL_Stenly of the eSheep character by Tatsutoshi Nomura (Fuji Television).

It is included in this repository under the licence held by the repository owner, who has confirmed
that licence covers this use. If you fork or redistribute this repository, make sure you have your
own right to the artwork, or delete this folder (the app falls back to the generated `woolly` pack).
